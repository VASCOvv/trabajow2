# Backend NestJS - Sistema de Soporte Técnico

## Etapa 1: Arquitectura Inicial

### Descripción
Creación de la arquitectura base del proyecto en NestJS para la gestión de solicitudes de soporte técnico. Se establece la estructura modular, controladores y servicios principales.

### Estructura de la Etapa 1
- `src/main.ts`: Punto de entrada de la aplicación NestJS.
- `src/app.module.ts`: Módulo principal de la aplicación.
- `src/soporte/soporte.module.ts`: Módulo encapsulado para el dominio de Soporte.
- `src/soporte/soporte.controller.ts`: Controlador base de soporte.
- `src/soporte/soporte.service.ts`: Servicio base para la lógica del dominio.

### Requisitos de Instalación y Ejecución
```bash
# Instalación de dependencias
npm install

# Modo desarrollo
npm run start:dev
```
